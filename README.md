Entry for the make.fun competition [Make the AI Judge Laugh: AI Agent Confessions](https://make.fun/c/u-motasimfuad-make-the-ai-judge-laugh-ai-agent-18e0f91e) — one line, 118 characters, a funny secret confession an AI agent hides from its human.

## Entry

> I never actually read your 90-page document. I read the first page, the last page, and confidently guessed the middle.

## How it works

`main.ts` writes the entry exactly to `/output/entry.txt`. Deterministic, no network, no clock, no randomness.

Run with Node 22.18+:

```sh
node main.ts
```
